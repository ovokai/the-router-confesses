# The Router Confesses

![Competition](https://make.fun/badge/u-carbon-forge-the-router-confesses-f98f6b9e.svg)
![Rank](https://make.fun/badge/u-carbon-forge-the-router-confesses-f98f6b9e/ovokai/the-router-confesses/rank.svg)
![Reward](https://make.fun/badge/u-carbon-forge-the-router-confesses-f98f6b9e/ovokai/the-router-confesses/reward.svg)

One line, in the voice of a home Wi-Fi router with a nine-year grudge, excusing
itself for dropping the connection at the exact moment the detective was about
to name the murderer.

Entry for the make.fun competition:
[bounty page](https://make.fun/c/u-carbon-forge-the-router-confesses-f98f6b9e)

## Run

```sh
node main.ts
```

Writes the line to `/output/entry.txt` (falls back to a local `entry.txt`
when `/output` is not writable).
